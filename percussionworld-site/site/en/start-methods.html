Teaching  /  Start methods

Method books

The Start series

A series of method books for young beginners, combining clear theory with graded exercises and solos — several of them published in Dutch, German and English.

  • Overview & methods
  • Start methods
  • Student achievements

Start voor / für Timpani

Start for Timpani

A timpani method for young students, in English, German and Dutch: note exercises, tuning, sticking patterns, contrasting meters and solos.

  • IMGReview by George FrockPAS Percussive Notes, selected reviews, June 2006

Start voor / für Snaredrum

Start for Snare Drum

A snare drum method for young students. The left-hand pages contain theory (in German and Dutch); the right-hand pages contain the exercises.

Start voor / für / for Drums

Start for Drums

Exercises and theory sections for the young drummer, including seven solos — with a preface by Heinz von Moisy.

Review of Start for Drums Pages 3 and 4 Pages 11 and 12 Pages 23 and 24 Preface by Heinz von Moisy

Heinz von Moisy — homepage

Start for Percussion

Start for Percussion

Easy solos for small set-ups, each introducing a family of percussion instruments.

Greet the Guiro – A Gogo Going Clink the Cymbals – Try the Triangle Templeblocks Tackle Bongo Battle

Start for Mallets

Start for Mallets

Fundamental exercises in different keys for two and four mallets, with a preface by Leo Ouderits. Reviewed in the Vaalser Weekblad.

Vaalser Weekblad, 16 March Vaalser Weekblad, 23 March

Start for Bugle · Methode voor klaroen

Start for Bugle

A method for bugle players (methode voor klaroen), written for the drum and bugle corps tradition.
